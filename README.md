# -BR-REGISTRAR
"BR-REGISTRAR is a specialized data management solution developed for the Divisional Secretariat of Sri Jayewardenepura Kotte. Built using Google Apps Script (GAS), it digitizes the business registration process, transforming manual record-keeping into a streamlined, automated workflow."
Key Features
Global Duplicate Prevention: Automatically scans all existing sheets (years) to prevent duplicate Business Names or Registration Numbers, ensuring data integrity.

Dynamic Sheet Management: Facilitates annual data organization by allowing users to select existing years or dynamically create new sheets for future registrations.

Multi-Owner Support: A flexible UI allows users to add multiple partners or owners for a single business entity, capturing names, NICs, and contact details seamlessly.

Live Financial Calculations: Features a real-time "Total Amount" calculator that instantly sums registration fees and delay charges as they are typed.

Smart Data Formatting: Includes automated Title Case conversion for names/addresses and Lower Case normalization for emails to maintain a professional database standard.

Integrated Validations: Built-in email format verification and mandatory field checks to minimize human error during data entry.

External Data Integration: Synchronizes with secondary spreadsheets to fetch real-time lists of GS Divisions.

🛠️ Tech Stack
Frontend: HTML5, CSS3 (Google Fonts/Font Awesome), JavaScript.

Backend: Google Apps Script (GAS).

Database: Google Sheets.
